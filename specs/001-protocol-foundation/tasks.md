# Tasks: Protocol Foundation

**Input**: Design documents from `/specs/001-protocol-foundation/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md

**Tests**: REQUIRED — constitution Principle II (test-first) and CLAUDE.md rule 8. Within
every story, test tasks precede implementation tasks and MUST fail before the
implementation lands. Golden vectors are generated by the Python reference implementation
and committed before any C++ codec that consumes them (research R-08).

**Organization**: grouped by user story (spec.md US1–US4). Story dependency: US2/US3/US4
consume the attribute tables that US1's generator emits, so US1 completes first; US4
attacks the decoders US2/US3 deliver.

**Risk tiers** (GOVERNANCE.md §3): tasks marked **(T3)** touch YAML/docs/workflows/CLAUDE.md
and MUST be delivered by a human or human-ratified PR — never dispatched to an agent
(DEFINITION-OF-READY). Tasks marked **(T2-dep)** introduce an approved dependency
(OPEN-QUESTIONS 2026-08-28) and land as their own PR. Everything else is T2 (`l3/`,
`pipeline.sh`, `tools/codegen.py`) or T1/T0.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies)
- **[Story]**: Which user story this task belongs to (US1–US4)
- Include exact file paths in descriptions

## Path Conventions

Repository root layout per plan.md: `protocol/` (YAML + `templates/`), `l3/` (new codec
library), `tools/` + `tools/refimpl/`, `tests/{unit,property,fuzz,vectors}/`,
`third_party/catch2/`, `esp32-host/components/omgp_l3/`, `build/gen/` (generated, not
committed).
